# TTX v1 Boundary

## Scope
- Admin‑managed
- Single‑user first
- One scenario initially
- 3–5 injects per session
- Structured responses
- Saved results
- Admin‑reviewable
- KB‑backed first, AI backup only

## Exclusions
- No multiplayer
- No large AI orchestration
- No full facilitator suite
- No scenario marketplace
- No heavy analytics
- No polished game system
