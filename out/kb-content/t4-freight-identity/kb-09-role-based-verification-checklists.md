# Role-Based Verification Checklists: Dispatch, Dock, Brokerage, and Management

These checklists define the specific verification steps each role must complete before authorizing a load action. They are designed to be used at the desk or dock — practical, role-specific, and built around the actual workflow of each position.

---

## Dispatch: Carrier Confirmation Checklist

Before confirming a carrier for a load:

- [ ] FMCSA authority status verified: "Authorized for Property" transport and authority is active.
- [ ] FMCSA insurance status verified: cargo insurance active.
- [ ] Authority age noted: if less than 90 days old, apply additional scrutiny and supervisor review.
- [ ] Carrier contact phone number called at FMCSA-listed number (not load board contact alone). Carrier is aware of this load.
- [ ] Driver name, tractor plate, and trailer number confirmed with carrier and entered in TMS.
- [ ] Pickup code generated and communicated to carrier through established channel (not in the same message as load details).
- [ ] Rate reviewed: not unusually below market for lane and load type.
- [ ] Any discrepancy from above → escalate to operations manager before confirming.

---

## Dispatch: Exception Handling Checklist

For any mid-load exception (destination change, carrier swap, consignee change):

- [ ] Exception request traced to original booking contact at established number (not via the requesting email or text).
- [ ] Verbal confirmation obtained and documented (who spoke, when).
- [ ] Operations manager or supervisor approval received.
- [ ] TMS record updated with change documentation.
- [ ] If carrier swap: new driver/equipment details obtained and verified before driver arrives.

---

## Dock Staff: Pickup Release Checklist

Before releasing any load to a driver:

- [ ] Driver name verified against load appointment record in TMS.
- [ ] Tractor plate verified against TMS record.
- [ ] Trailer plate/number verified against TMS record.
- [ ] Driver states the correct pickup code.
- [ ] Seal number recorded on BOL and in TMS.
- [ ] BOL fields confirmed against TMS: shipper name, consignee, cargo description, destination.

If any item does not match:
- [ ] Do not release the load.
- [ ] Contact dispatch on the established number immediately.
- [ ] Document what the driver presented (name, CDL, plate numbers, any paperwork).
- [ ] Await dispatch confirmation before any action.

---

## Brokerage Operations: New Carrier Setup Checklist

Before entering a new carrier in the system and assigning them to a load:

- [ ] FMCSA lookup completed: authority active, for property, insurance active, authority age acceptable.
- [ ] FMCSA-listed contact phone called: carrier is a real operating company with knowledge of their operations.
- [ ] Carrier packet received: insurance certificate, W-9, bank details.
- [ ] Bank details cross-referenced against FMCSA information where possible.
- [ ] Rate confirmation reviewed: not below market for lane and load type.
- [ ] Carrier file created in TMS with FMCSA data, verified phone number, and setup date.

For carriers where any of the above cannot be verified:
- [ ] Escalate to brokerage supervisor before assignment.

---

## Management / Operations Leader: High-Risk Load Checklist

For loads meeting any of the following: high-value cargo, new carrier with less than 90 days authority, prior red flags on this lane or carrier:

- [ ] Personally reviewed FMCSA verification steps.
- [ ] Called carrier's management contact at FMCSA-listed number (not operational dispatch contact alone).
- [ ] Confirmed with shipper or customer that load details are as expected.
- [ ] Extra pickup controls applied: enhanced equipment verification, pickup code confirmed.
- [ ] Load flagged in TMS for enhanced monitoring during transit.

---

## Management: Post-Incident Checklist

If a fraud attempt or theft is suspected:

- [ ] Load held pending investigation.
- [ ] All relevant communications preserved (do not delete emails, texts, or TMS notes).
- [ ] Carrier's FMCSA record flagged for future reference.
- [ ] Shipper or customer notified of situation (coordinate with legal/leadership).
- [ ] Law enforcement contacted (FBI field office for cargo theft) if fraud confirmed.
- [ ] Internal documentation completed: what happened, what was caught, what controls were in place.
- [ ] Process review: which verification step, if any, was bypassed or insufficient?

---

These checklists are living documents. If a new fraud pattern appears that is not covered, add a step to the relevant checklist and train staff on the update.
