# Red Flags Library by Workflow Stage

This library maps cargo theft and identity fraud red flags to the specific workflow stage where they appear. Use this as a reference during load tendering, carrier vetting, pickup, and settlement to identify when to pause and verify.

## Tender Stage

| Red Flag | Risk |
|----------|------|
| Carrier bid is significantly below market rate for the lane | High |
| Carrier's FMCSA authority is newly issued (days to weeks old) | High |
| Carrier whose authority was recently reinstated | Medium–High |
| Carrier bid comes with pressure to accept immediately | Medium–High |
| Carrier contact information does not match FMCSA records | High |
| Carrier's phone number goes unanswered or reaches someone unfamiliar with the load | High |
| Carrier profile on load board recently modified (days before bid) | Medium |
| Rate confirmation paperwork has inconsistencies with FMCSA data | High |

## Carrier Vetting / Onboarding Stage

| Red Flag | Risk |
|----------|------|
| Insurance certificate cannot be verified with the insurer directly | High |
| Carrier packet bank details do not match any on-file records for that carrier | High |
| New entity name that does not match FMCSA carrier name | High |
| Carrier representative insists on verifying through email only (no phone verification) | High |
| Carrier representative provides a callback number different from FMCSA | Medium–High |
| Carrier has no prior payment history with your company and the load is high-value | Medium |

## Pickup Stage

| Red Flag | Risk |
|----------|------|
| Arriving driver's name does not match the load appointment record | High |
| Tractor plate does not match what dispatch confirmed | High |
| Trailer plate or number does not match | High |
| Driver does not know the pickup code | High |
| Driver has paperwork showing a different carrier name or MC number | High |
| Driver says "the other driver was switched last minute" with no dispatcher confirmation | High |
| Driver seems unfamiliar with the route, shipper, or load details | Medium |
| Driver is accompanied by an unexpected second person | Medium |
| Last-minute change to driver or equipment communicated via text to a non-dispatch contact | High |

## In-Transit Stage

| Red Flag | Risk |
|----------|------|
| Request to change delivery destination arrives via a new email thread or text | High |
| Reconsignment request from a contact not on the original load record | High |
| Load tracking goes dark (GPS off, driver unreachable) after pickup | High |
| Carrier calls to say they "need to sub out" the load to another driver | Medium–High |
| Driver requests to drop and leave the trailer at an unscheduled location | High |
| Load arrives at unscheduled location and requests are made for early release | High |

## Delivery and POD Stage

| Red Flag | Risk |
|----------|------|
| Consignee reports non-arrival but carrier has submitted POD | High |
| POD signature does not match consignee's expected signatory | Medium–High |
| POD submitted without prior delivery confirmation in TMS | Medium |
| Photos in POD do not match the consignee's actual facility | High |
| Alternate consignee shows up without prior written authorization | High |

## Settlement and Payment Stage

| Red Flag | Risk |
|----------|------|
| Payment routing change request arrives by email for this load | High |
| "New factor" or "new bank" notice with no prior relationship or verification | High |
| Carrier representative cannot be reached at their established number after delivery | Medium |
| Settlement dispute claiming delivery occurred but consignee denies receipt | High |

---

## Using This Library

No single red flag is always fraud — legitimate exceptions happen. But when multiple red flags appear on the same load, the probability of fraud increases sharply.

**Two or more red flags at the same stage = escalate to supervisor before proceeding.**

Document the flags you observed in your TMS notes or exception log. This documentation is valuable if a fraud investigation is opened later.
